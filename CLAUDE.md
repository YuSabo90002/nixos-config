## Build and Deploy Commands

```bash
# Rebuild and switch to new configuration (current host, selected by `hostname -s`)
nix run .#activate

# Activate a specific host by name
nix run .#activate Yuta-PC

# Update all flake inputs
nix flake update

# Update a specific input
nix flake update <input-name>

# Validate configuration
nix flake check
```

## Architecture

A NixOS flake configuration currently hosting one machine: `Yuta-PC` (x86_64-linux, AMD CPU/GPU).

### Flake Structure

`flake.nix` uses **nixos-unified** (`mkFlake` + `flakeModules.autoWire`). Everything is auto-wired by
directory convention — there is no explicit `nixosConfigurations` list to maintain:

| Directory | Becomes |
|---|---|
| `configurations/nixos/<name>.nix` or `<name>/default.nix` | `nixosConfigurations.<name>` |
| `modules/nixos/*` | `nixosModules.*` |
| `modules/home/*` | `homeModules.*` |
| `overlays/*` | `overlays.*` |
| `packages/*` | `packages.*` (evaluated with `callPackage`) |

Adding a host means dropping a new directory under `configurations/nixos/` — nothing else.

Key inputs: `nixpkgs` (nixos-26.05), `nixpkgs-unstable`, `home-manager`, `disko` (disk partitioning),
`agenix` (secrets), `ags`/`astal` (desktop shell), `nixvim`.

An overlay exposes `nixpkgs-unstable` as `pkgs.unstable` for packages that need the bleeding-edge channel.

### Module Layout

- **`configurations/nixos/<host>/`** — Per-host configuration. **Anything tied to one specific machine
  belongs here, not in `modules/nixos/`.**
  - `default.nix` — hostname, user, agenix identity/secrets, host-specific imports
  - `hardware.nix` — `nixos-generate-config` output (kernel modules, CPU microcode)
  - `disko.nix` — disk layout for this machine

- **`modules/nixos/`** — System modules shared by all hosts
  - `default.nix` — nix settings/GC, bootloader, SSH + mosh (tailnet-only), podman, direnv, zram, kmscon
  - `desktop.nix` — Hyprland (via UWSM), greetd + AGS greeter, PipeWire, polkit, Steam, Bluetooth
  - `locale.nix` — ja_JP.UTF-8, Asia/Tokyo, fcitx5-skk, CJK fonts
  - `networking.nix` — systemd-networkd, iwd, resolved
  - `tailscale.nix` — Tailscale + Tailscale SSH
  - `hori-wheel.nix` — HORI wheel HID quirk; imported by `Yuta-PC` only

- **`modules/home/`** — Home-manager modules (`default.nix` imports the rest)
  - User packages, AGS shell, Hyprland settings, shell/terminal/tmux/editors/xdg

- **`ags/`** — AGS v3 (Astal) sources: `widget/` for the user shell, `greeter/` for the login screen.
  New files must be `git add`ed or they will not be part of the flake source.
- **`hypr/hyprland.lua`** — Hyprland config in Lua (`hl.*` API)
- **`pkgs/`**, **`packages/`** — Local packages (`pkgs/` holds ones that cannot be auto-wired, e.g. unfree)
- **`secrets/`** — agenix-encrypted secrets (user password)

### Desktop Stack

Hyprland (Wayland tiling WM) driven by **AGS v3 / Astal**, which provides the bar, launcher and
notifications in one shell process. Plus: hyprpaper (wallpaper), hyprlock + hypridle (lock/idle),
alacritty (terminal), grim+slurp (screenshots), fuzzel (used for the `sudo -A` askpass prompt).
Login screen is greetd running a dedicated AGS greeter. Japanese input via fcitx5-skk.

### Secrets

agenix decrypts with the machine's SSH **host** key at `/etc/ssh/ssh_host_ed25519_key`
(`age.identityPaths`). That key is generated by sshd on first boot and is not in git — so a new host's
public key must be added to `secrets/secrets.nix` and the secrets re-keyed (`agenix -r`) before that
host can decrypt anything.

## Language and Conventions

- All NixOS/home-manager configuration is written in Nix
- User comments and commit messages are in Japanese
- Host-specific settings go in `configurations/nixos/<host>/`; `modules/nixos/` stays host-agnostic
- `stateVersion` is `25.11` for both system and home-manager
- `mutableUsers = false` — user passwords managed via agenix, not `passwd`
